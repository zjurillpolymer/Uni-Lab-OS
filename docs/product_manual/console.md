# Uni-Lab OS 快速上手

本页介绍 Uni-Lab OS 网页的日常入口、页面状态和基本操作。产品能力与对象关系见[认识 Uni-Lab OS](overview.md)；从零部署请先阅读[系统安装](installation.md)，设备包目录和配置规范见[设备包规范与系统启动](unilabos-installation.md)。

## 打开与识别当前界面

Uni-Lab OS 的网页入口地址是：

```text
<BACKEND_URL>/console/
```

本手册的日常操作步骤均以 Uni-Lab OS 网页为准。Theia Workbench 等工具只用于开发，不属于业务人员的日常产品入口。

## 连接状态

页头会出现以下状态：

| 状态 | 含义 | 应对 |
| --- | --- | --- |
| 正在加载 | 首次拉取运行状态。 | 短暂等待。 |
| 实验室在线 | 最近一次连接和数据读取成功。 | 可以继续操作。 |
| 正在重连 | 连接中断，页面保留最后一次成功快照。 | 只读核对，暂停写操作。 |
| 演示数据 | 页面展示样例而非当前实验室事实。 | 不要据此执行实验。 |
| 连接失败 | API 不可达或返回错误。 | 检查服务与网络。 |

断线和重连期间，Uni-Lab OS 页面会保留最后成功读取的只读快照，但不会把它当作当前事实，也会暂停写操作。

## 启动模式

页头可以显示并切换启动模式：

- `develop`：允许标准 step Task、暂停、选择下一节点和逐步执行；同一时间不接受第二个开发任务。
- `product`：运行已发布工作流并允许多个任务并行，由调度器仲裁共享资源；不开放单步调试。

模式切换只影响之后创建的任务，不会迁移或改写既有任务。切换前请处理页面列出的阻塞项。

## 总监控页能告诉你什么

总监控页适合快速回答：

- 工作流运行时是否 ready；
- 当前有多少任务运行、等待或需要处理；
- 物料库存是否有明显异常；
- 最近发生了哪些任务与资源事件。

当前实验室布局视图主要展示配置和占位关系，不是设备实时遥测。运行报告导出、设备详情、全局通知中心和用户权限菜单尚未接入；全局搜索也只会引导你使用各页面自身的搜索框。

## 刷新与一致性

执行写操作后，以页面重新拉取的服务端结果为准。物料位置和试剂库存更新使用修订号做并发保护：如果另一位用户或任务先更新了同一对象，你会收到冲突提示，需要刷新后基于最新状态重新操作。

:::{warning}
不要用浏览器刷新、重复点击或手工修改请求来“绕过”冲突。任务、库存和设备动作使用幂等键与修订检查来防止重复执行；绕过这些约束会破坏恢复依据。
:::
