试剂管理¶

阅读角色

  • 业务负责人：确认物料名称、规格、容量、放置规则、条码和现场状态。

  • 开发人员：实现物料模板、放置位约束、启动图实例和工作流资源合同。

  • 验收人员：核对实物兼容性、位置关系、数量变化、搬运和异常恢复。

试剂管理把“化学身份”和“实际库存容器”分开维护。一个试剂目录项可以对应多瓶库存，每瓶库存关联一个物料容器、数量、单位、浓度、来源和历史。

目录与库存¶

在“试剂”页切换两个视图：

  • 目录回答“这是什么试剂”，包含名称、别名、CAS、分子式、分子量、SMILES、物态和说明。

  • 库存回答“实验室里哪一瓶有多少”，包含容器、条码、数量、单位、浓度、来源和当前位置。

目录存在不代表库存中已经有对应容器；录入库存前必须先有目录项和可用空容器。

新建试剂目录¶

  1. 打开“目录”，点击“新增试剂目录”。

  2. 填写名称；可以先输入 CAS 号查询化合物信息。

  3. 核对自动补全的名称、分子式、分子量和 SMILES。

  4. 补充物态、别名和说明，然后保存。

CAS 查询依赖外部化合物服务和网络。查询失败时可以手工填写；即使自动补全成功，也应由实验人员核对身份，不能仅凭返回内容直接用于实验。

SMILES 当前是文本字段，不提供结构绘图编辑器。3D 结构读取依赖目录数据和服务配置。

录入和维护库存¶

  1. 切换到“库存”，点击“录入试剂”。

  2. 选择试剂目录项。

  3. 选择尚未绑定试剂、且模板带 container 标签的物料容器。

  4. 填写数量、单位、浓度、来源和说明。

  5. 保存后按化学身份、容器和条码核对结果。

可以编辑数量、浓度和说明。更新携带期望修订号，发生冲突时先刷新。删除库存记录前，系统会检查是否存在任务预留；被预留的库存不能删除。被库存引用的目录项也不能直接删除。

搜索¶

库存视图支持按试剂名称、CAS、容器名称或条码筛选；目录视图支持按名称、别名、CAS 或分子式筛选。清空搜索框恢复完整列表。

分装试剂¶

分装把一个源瓶的试剂原子性地分配到一个或多个空容器：

  1. 在库存列表找到源瓶，点击“分装”。

  2. 选择目标容器类型和具体空容器。

  3. 填写每个目标容器的分装量；可继续添加目标。

  4. 核对“本次分装总量”和“源瓶剩余”。

  5. 确认分装，再检查源瓶与新瓶记录。

系统会校验源瓶修订、目标容器唯一且为空、数量非负和总量守恒。整个命令原子执行：任一目标失败时，不应只扣减源瓶或只创建部分目标记录。

历史、来源与消耗¶

点击库存行的历史入口可以查看：

  • 当前余量和修订号；

  • 试剂库存 UUID 与物料容器 UUID；

  • 录入、编辑、补充、分装和数量变化；

  • 分装父子来源关系；

  • 工作流创建的数量预留与实际消耗。

历史是审计依据，不应用删除后重建的方式“修正”历史。发现数量或身份错误时，先停止依赖该库存的新任务，再按允许的更正操作处理。

批量导入¶

Uni-Lab OS API 支持目录和库存的批量创建，以及 .json、.csv、.tsv、.xlsx 文件导入。单个文件最大 5 MiB、最多 500 行。页面没有批量导入按钮时，应由有权限的管理员通过本次安装的 <BACKEND_URL>/api/docs 操作，并先在测试数据上校验字段和原子模式。
